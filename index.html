大樹教練製作網頁的綜合指令集

個人品牌網頁、課程活動網頁、協會網站，都用同一行。TAVA AI 和 MUSE 都能讀，它們自己判斷「我是誰」和「這次做哪一種」，照各自的方式做到交付。

① 複製這一行，後面接這次的資料

請完整讀完這份入口指令再照做（自己判斷你是 TAVA 還是 MUSE、這次做哪一種網頁）：https://coach1973.github.io/bigtree-web-guide/go.txt ｜這次的資料：

　已複製 ✓

「這次的資料：」後面貼上人名＋連結、課程的日期地點費用講師，或協會名稱＋理事長就好；資料越多越準。

要做官方網站或線上課程（學員登入看影片），請在資料裡直接寫「做官方網站」或「做線上課程」。沒寫，AI 就不會去讀那兩份，平常省 token、也不分心。

② 教練接下來只要做這幾步

用 TAVA 做
  1. 下載 TAVA 給的 ZIP
  2. 上傳到策展中心
  3. 把出圖清單交給小龍蝦出圖，圖會照編號自動換進網頁
用 MUSE 做
  1. 下載 MUSE 給的 ZIP（圖已經放好）
  2. 上傳到策展中心 → 結束

之後要改：叫 MUSE 寫成「修改指令」，交給小龍蝦或 Claude Code 去改。

AI 怎麼分辨（回覆第一行會寫「判定：……」）

我是誰確定自己是 MUSE → 自己出圖、一次做完。其他情況（TAVA，或不確定）一律當 TAVA → 不生圖，只寫出圖清單交給 LK888，避免誤扣點。
C 協會網站主角是協會、學會、商會等組織（有理事長、理監事、會員、入會）。
B 課程活動資料裡有日期、時間、地點、費用、名額、報名其中兩項以上。協會辦的一場活動也算 B。
A 個人品牌主要是一個人，沒有要報名的場次。

判斷錯了，直接跟它說「改做 A／B／C」或「你是 MUSE」。資料裡寫明的，以您寫的為準。

指令集裡有哪些檔案

  • 入口：判定＋所有網頁共用的規則（每次都讀）
  • A 個人品牌、B 課程活動、C 協會網站（三選一）
  • 28 招特效庫（挑特效時才讀；示範頁）
  • TAVA 交付方式、MUSE 交付方式（二選一）

每次 AI 先讀「入口＋一種網頁＋自己的交付方式」（約一萬字，是以前 MUSE 總指令的一半），做到挑特效時才讀特效庫；分段讀、每段只放這次用得到的，比較不會漏。圖片一律壓到單張 300KB 以下（網頁用；印刷另外定）。
